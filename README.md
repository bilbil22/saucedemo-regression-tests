# SauceDemo Regression Tests

This project demonstrates a regression test suite for SauceDemo using Python - Pytest and Playwright.

The project was initially developed using a linear, script-based Playwright approach. It was later refactored to use the Page Object Model (POM) design pattern, improving maintainability by separating test logic from page interactions, reducing code duplication, and centralizing UI locators.

Due to time constraints, the focus was on:
- covering key user flows (login, cart, checkout)
- keeping the test structure simple and readable
- demonstrating automated regression capability

The suite includes both core scenarios and extended coverage.

During development, I focused on understanding Playwright and structuring maintainable test automation rather than only maximizing test count.
